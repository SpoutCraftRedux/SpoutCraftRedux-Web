`player.spoutCraftRedux().movement()` returns the player's `MovementModifiers`. Each setting is a multiplier, where 1 means normal:

```java
MovementModifiers movement = player.spoutCraftRedux().movement();
movement.setGravityMultiplier(0.5);   // half gravity
movement.setWalkingMultiplier(1.2);   // 20% faster
movement.setJumpingMultiplier(1.5);   // higher jumps
```

`reset()` puts all three back to 1.

| Method | Vanilla attribute |
|---|---|
| `get/setGravityMultiplier` | `gravity` |
| `get/setWalkingMultiplier` | `movement_speed` |
| `get/setJumpingMultiplier` | `jump_strength` |

## How it works

The multipliers are transient attribute modifiers (`MULTIPLY_SCALAR_1`) with the keys `spoutcraftredux:gravity_multiplier`, `spoutcraftredux:walking_multiplier` and `spoutcraftredux:jumping_multiplier`. Because vanilla clients already understand attributes, movement works the same for every player, modded or not.

- A multiplier applies on top of the player's other modifiers, such as Speed potions or armor.
- Gravity 0 means no gravity.
- Changes last until the player logs out or you call `reset()`. They aren't saved.

A multiplier must be 0 or more and finite. Anything else throws `IllegalArgumentException`.

Velocity, flight and fall distance already work through the normal Bukkit API.
