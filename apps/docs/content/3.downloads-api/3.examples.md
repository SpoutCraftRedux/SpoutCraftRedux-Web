## Download the latest server

```bash [Terminal]
curl -fL -o spoutcraftredux.jar \
  https://api.spoutcraftredux.org/v2/spoutcraftredux/26.3/latest/download
```

`-f` makes curl fail on HTTP errors instead of saving the error body as a jar.

## Download the latest client

`-OJ` keeps the file name the server sends:

```bash [Terminal]
curl -fL -OJ \
  https://api.spoutcraftredux.org/v2/spoutcraftredux-fabric/26.3/latest/download
```

## Pin a build

Use a build number for reproducible setups:

```bash [Terminal]
curl -fL -o spoutcraftredux.jar \
  https://api.spoutcraftredux.org/v2/spoutcraftredux/26.3/42/download
```

## Find the latest build number

With [jq](https://jqlang.org):

```bash [Terminal]
curl -fs https://api.spoutcraftredux.org/v2/spoutcraftredux/26.3 | jq -r '.builds.latest'
```

## Find the current Minecraft version

```bash [Terminal]
curl -fs https://api.spoutcraftredux.org/v2/spoutcraftredux | jq -r '.metadata.current'
```

## Verify a download

Compare the jar's SHA-256 with the build's `sha256` field:

```bash [Terminal]
expected=$(curl -fs https://api.spoutcraftredux.org/v2/spoutcraftredux/26.3/42 | jq -r '.sha256')
echo "$expected  spoutcraftredux.jar" | shasum -a 256 -c -
```

On Linux, `sha256sum -c -` works the same way.

## Update script

This script downloads the latest server build only when it differs from the one already on disk:

```bash [update.sh]
#!/usr/bin/env bash
set -euo pipefail

api=https://api.spoutcraftredux.org/v2/spoutcraftredux
version=$(curl -fs "$api" | jq -r '.metadata.current')
build=$(curl -fs "$api/$version/latest")
sha=$(echo "$build" | jq -r '.sha256')

if [ -f spoutcraftredux.jar ] && echo "$sha  spoutcraftredux.jar" | shasum -a 256 -c - >/dev/null 2>&1; then
  echo "Already on build $(echo "$build" | jq -r '.build')"
  exit 0
fi

curl -fL -o spoutcraftredux.jar.tmp "$api/$version/$(echo "$build" | jq -r '.build')/download"
echo "$sha  spoutcraftredux.jar.tmp" | shasum -a 256 -c -
mv spoutcraftredux.jar.tmp spoutcraftredux.jar
echo "Updated to $version build $(echo "$build" | jq -r '.build')"
```

## List recent commits

```bash [Terminal]
curl -fs https://api.spoutcraftredux.org/v2/spoutcraftredux/26.3/latest \
  | jq -r '.commits[] | "\(.hash[0:7]) \(.description)"'
```
