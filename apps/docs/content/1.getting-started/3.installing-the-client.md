The SpoutCraft Redux client is a Fabric mod. It is optional: without it, you can still join SpoutCraft Redux servers as a vanilla player, but you miss the features that need the mod, such as custom GUIs and sky changes.

## Requirements

- Minecraft Java Edition **26.3**
- **Java 25** (the official launcher bundles a suitable runtime)
- [Fabric Loader](https://fabricmc.net/use/installer/) **0.20.1** or newer
- [Fabric API](https://modrinth.com/mod/fabric-api) for 26.3

## Install

::steps{level="3"}

### Install Fabric Loader

Download the [Fabric installer](https://fabricmc.net/use/installer/), choose Minecraft **26.3**, and install. Your launcher gets a new `fabric-loader-26.3` profile. Third-party launchers such as Prism Launcher can create a Fabric instance directly.

### Add Fabric API

Download the Fabric API build for 26.3 and put it in the `mods` folder of your game directory (`.minecraft/mods` for the official launcher).

### Add SpoutCraft Redux

Download the client mod from [spoutcraftredux.org/downloads](https://spoutcraftredux.org/downloads) and put it in the same `mods` folder. You can also fetch it from the downloads API:

```bash [Terminal]
curl -fL -OJ \
  https://api.spoutcraftredux.org/v2/spoutcraftredux-fabric/26.3/latest/download
```

### Launch and join

Start the game with the Fabric profile and join a SpoutCraft Redux server. The server confirms the connection during login; `/spoutcraftredux list` on the server shows you as modded.

::

## On other servers

The mod does nothing on servers that are not running SpoutCraft Redux. All state a server sets (keybinds, HUD changes, sky settings) is kept per session and cleared when you disconnect, so nothing carries over to the next server.

## Privacy and safety

- The server sends data, never code. The mod does not run scripts or classes from the server.
- Images the server sends are checked against their SHA-256 hash, limited to PNG, and size-capped.
- The mod never reads your clipboard, takes screenshots, or opens URLs without asking.
- Server keybinds only report keys the server declared, never raw keyboard input.

::note
A settings screen (through Mod Menu) to switch the mod off per server and control runtime downloads is planned.
::
