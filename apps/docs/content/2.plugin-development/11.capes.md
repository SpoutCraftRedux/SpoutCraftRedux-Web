## Capes

A server can set a cape texture on any player. The texture is sent as a runtime asset: content-addressed by SHA-256, PNG only, and size-limited. Players with the client mod see the cape on that player.

```java
player.spoutCraftRedux().appearance()
    .cape(CapeTexture.fromPlugin(this, "capes/founder.png"));
```

Players without the client see the player's normal cape or none.

## Nameplates

Multi-line, coloured name titles are planned too. For players with the client mod they replace the native nameplate; players without it see the normal nameplate.
