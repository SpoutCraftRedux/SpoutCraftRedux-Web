## Built-in sounds

Built-in sounds work through the normal Paper API today and need no client mod:

```java
player.playSound(location, Sound.ENTITY_EXPERIENCE_ORB_PICKUP, 1.0f, 1.0f);
```

## Custom sounds

Plugins will be able to ship sound files in an `assets/` folder. The server collects assets from all plugins into one generated resource pack, hosts it, and sends it to every client with its SHA-1 hash. Because the pack goes to vanilla clients too, custom sounds play for everyone.

```java
player.playSound(location, "myplugin:shop.open", 1.0f, 1.0f);
```

## Streaming from a URL

The original Spoutcraft could play music from a URL. SpoutCraft Redux plans this as an optional feature: HTTPS only, and only if the player allows it for that server.

## Music control

With the client mod, plugins will be able to stop music with a fade-out and listen for background music changes. On vanilla clients, stopping a sound cuts it off without a fade.
