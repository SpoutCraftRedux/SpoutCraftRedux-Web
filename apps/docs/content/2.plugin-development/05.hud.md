Each player has a HUD that you can attach the same widgets to as a [popup](/plugin-development/guis). HUD widgets are drawn over the game and take no input.

```java
Hud hud = player.spoutCraftRedux().hud();

Label mana = new Label(Component.text("Mana"))
    .setGeometry(6, 6, 0, 0);
Gradient bar = new Gradient(0xFF2060FF, 0xFF1030A0)
    .setGeometry(6, 18, 80, 6);

hud.attach(mana, bar);
```

Change a widget to update it, for example `bar.setWidth(manaPercent * 80 / 100)`. The change goes to the player straight away. `hud.detach(widget)` removes one.

Placement works the same as on popups: `setGeometry`, `setAnchor` and the `SCALE` layout are described on the [GUIs page](/plugin-development/guis#placing-widgets).

On the client the HUD is a Fabric HUD element called `spoutcraftredux:server_hud`.

## Vanilla HUD elements

The same `Hud` can hide and move Minecraft's own HUD elements, such as the health bar or the hotbar:

```java
Hud hud = player.spoutCraftRedux().hud();
hud.setSurvivalHudVisible(false)
    .setVanillaOffset(VanillaHudElement.HOTBAR, 0, -40);
```

| Method | What it does |
|---|---|
| `setVanillaVisible(VanillaHudElement, boolean)` | Hides or shows one element |
| `isVanillaVisible(VanillaHudElement)` | Whether it's shown |
| `setVanillaOffset(VanillaHudElement, int x, int y)` | Moves it by that many GUI pixels. Right and down are positive, and `0, 0` puts it back. |
| `getVanillaOffsetX(VanillaHudElement)`, `getVanillaOffsetY(VanillaHudElement)` | Reads the offset back |
| `setSurvivalHudVisible(boolean)` | Hides or shows health, armor, food, air and experience (bar and level) together. That set is `VanillaHudElement.SURVIVAL`. |
| `resetVanilla()` | Shows everything in its normal place again |

The setters return the `Hud`, so they chain.

`VanillaHudElement` is one of `HOTBAR`, `HEALTH`, `ARMOR`, `FOOD`, `AIR`, `MOUNT_HEALTH`, `EXPERIENCE_BAR` (which also covers the jump bar and the locator bar), `EXPERIENCE_LEVEL`, `CROSSHAIR`, `HELD_ITEM_NAME`, `EFFECTS`, `BOSS_BAR`, `SCOREBOARD`, `ACTION_BAR`, `TITLE`, `CHAT`, `PLAYER_LIST` and `SUBTITLES`.

- Changing one element doesn't move the others. Hiding health doesn't pull armor down to fill the gap.
- Moving chat only moves where it's drawn.
- Settings last until you change them or the player disconnects.

## Players without the client

HUD widgets and vanilla element changes only apply to players with the client mod. Everyone else sees the normal HUD. See [players without the client](/plugin-development/players-without-the-client).

## Protocol

Clients that support the HUD report `hud.v1`. HUD widgets use `spoutcraftredux:widget_update` and `widget_remove` with screen id 0. Vanilla element changes use `spoutcraftredux:vanilla_hud`, which sends the full list of changed elements each time (name, visible, x, y). The client ignores names it doesn't know.
