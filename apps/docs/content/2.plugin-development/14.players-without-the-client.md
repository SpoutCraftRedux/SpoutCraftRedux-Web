Players without the client mod can still join a SpoutCraft Redux server, unless it has [custom items](/plugin-development/custom-items). Like the original Spoutcraft, though, the client features don't fall back to something vanilla: they simply do nothing for those players. Instead, the server tells them where to get the client.

## What works for everyone

| Feature | Players with the client | Players without it |
|---|---|---|
| Joining the server | Yes | Yes, unless the server has custom items |
| [Movement](/plugin-development/movement) | Yes | Yes, because it uses vanilla attributes |
| [Resource packs](/plugin-development/images-and-resource-packs#resource-packs), including [custom sounds](/plugin-development/sounds) | Yes | Yes, it's a normal server resource pack |
| [Notifications](/plugin-development/notifications) | Popup | Nothing |
| [Popup GUIs](/plugin-development/guis) | Native screens | Nothing |
| [HUD widgets](/plugin-development/hud) | Drawn over the game | Nothing |
| [Images](/plugin-development/images-and-resource-packs) | `Texture` widgets | Nothing |
| [Key bindings](/plugin-development/keybinds) | Under Custom Bindings | Nothing; presses never arrive |

The planned features ([sky](/plugin-development/sky), [waypoints](/plugin-development/waypoints), [capes](/plugin-development/capes)) follow the same rule.

## The download message

When a player joins without the client, the server sends them a chat message set by `missing-client.message` in `spoutcraftredux.yml`. It uses [MiniMessage](https://docs.advntr.dev/minimessage/format.html), and the default links to https://spoutcraftredux.org/downloads:

```yaml [spoutcraftredux.yml]
missing-client:
  message: "<gold>This server uses <yellow>SpoutCraft Redux</yellow>. Get the client at <click:open_url:'https://spoutcraftredux.org/downloads'><aqua><underlined>spoutcraftredux.org</underlined></aqua></click> for the full experience."
```

Set it to an empty string to send nothing.

Plugins can change or remove the message per player in `SpoutCraftReduxClientMissingEvent`:

```java
@EventHandler
public void onMissing(SpoutCraftReduxClientMissingEvent event) {
    event.setMessage(Component.text("Install SpoutCraft Redux to see the shop menu."));
    // or event.setMessage(null) to send nothing
}
```

## Servers with custom items

Custom items are real registry entries, and a client without the mod can't load them. Once any plugin registers a [custom item](/plugin-development/custom-items), players without the client are disconnected while joining, with the `missing-client.kick-message` from `spoutcraftredux.yml`:

```yaml [spoutcraftredux.yml]
missing-client:
  kick-message: "<gold>This server needs <yellow>SpoutCraft Redux</yellow>.</gold><newline><gray>Get the client at <aqua>spoutcraftredux.org/downloads</aqua>"
```

Links can't be clicked on the disconnect screen, so the default spells out the address.

## Detecting the client

To offer something else to players without the client, such as a command, check the player view:

```java
if (!player.spoutCraftRedux().isModded()) {
    player.sendMessage(Component.text("Use /shop instead."));
}
```

Or listen for the [handshake events](/plugin-development/player-api#handshake-events).
