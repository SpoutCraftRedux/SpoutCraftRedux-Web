Spoutcraft plugins loved `setGravityMultiplier(0.5)`. Modern Minecraft covers most of this with vanilla attributes, so the SpoutCraft Redux movement API is a thin wrapper over them, and it **works for every player**, modded or not.

```java
player.spoutCraftRedux().movement()
    .gravity(0.5)
    .jump(1.5)
    .walkSpeed(1.2);
```

## Mapping to attributes

| Movement setting | Vanilla attribute |
|---|---|
| `gravity` | `gravity` |
| `walkSpeed` | `movement_speed` |
| `jump` | `jump_strength` |
| `swimSpeed` | `water_movement_efficiency` |

Values are multipliers on the player's base value, so `gravity(0.5)` halves gravity.

## Doing it today

Until the wrapper lands, set the attributes directly with the Paper API:

```java
player.getAttribute(Attribute.GRAVITY).setBaseValue(0.04);
```

Velocity, flight and fall distance already work through the normal Bukkit API.
