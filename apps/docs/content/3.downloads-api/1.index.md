The downloads API at `https://api.spoutcraftredux.org` serves every published build of the SpoutCraft Redux server and client. Its layout follows the Purpur downloads API, so tools that already speak to Purpur need little more than a new base URL and project name.

## Base URL

```text
https://api.spoutcraftredux.org/v2
```

All responses are JSON, except the `download` endpoints, which return the jar.

## Projects

| Project | What it is | Example file |
|---|---|---|
| `spoutcraftredux-server` | The server (Purpur fork, paperclip jar) | `spoutcraftredux-paperclip-26.3.build.42-stable.jar` |
| `spoutcraftredux-fabric` | The Fabric client mod | `spoutcraftredux-fabric-0.1.0.jar` |

## Versions and builds

- A **version** is a Minecraft version, such as `26.3`.
- A **build** is a numbered CI build for that version, starting at `1`. Higher numbers are newer.
- `latest` can be used in place of a build number. It always means the newest build whose `result` is `SUCCESS`.

## Endpoints at a glance

| Method | Path | Returns |
|---|---|---|
| `GET` | `/v2` | All projects |
| `GET` | `/v2/{project}` | Versions of a project |
| `GET` | `/v2/{project}/{version}` | Builds of a version |
| `GET` | `/v2/{project}/{version}/{build}` | One build's details |
| `GET` | `/v2/{project}/{version}/latest` | The latest successful build's details |
| `GET` | `/v2/{project}/{version}/{build}/download` | The jar |
| `GET` | `/v2/{project}/{version}/latest/download` | The latest successful jar |

See [endpoints](/downloads-api/endpoints) for the full response formats and [examples](/downloads-api/examples) for ready-to-use scripts.

## Caching

Downloads of a numbered build never change and are served with a one-year immutable cache header. `latest` downloads are cached for 60 seconds.
