A notification is a small popup that slides down at the top right of the screen. It has a yellow title, a white message and an item drawn at the left.

```java
player.spoutCraftRedux().sendNotification(
    Component.text("Quest complete"),
    Component.text("You found the old mine"),
    ItemStack.of(Material.IRON_PICKAXE)
);
```

It stays up for 7.5 seconds. Pass a `Duration` to change that:

```java
player.spoutCraftRedux().sendNotification(title, message, icon, Duration.ofSeconds(15));
```

## Rules

- The title and the message are one line each, at most 26 visible characters. Formatting doesn't count towards the limit. A longer line throws `IllegalArgumentException`.
- The icon can be any item except air.
- The time must be more than 0 and at most 60 seconds.
- A new notification replaces the one on screen. They don't queue.

## Players without the client

Players without the client mod get nothing. You don't need to check `isModded()` first; calling it for them is safe. See [players without the client](/plugin-development/players-without-the-client).

## Capability

Clients that can show the popup report `notification.v1`. The server sends it on the `spoutcraftredux:notification` channel, carrying the title and message as JSON text components, the item id and the display time in milliseconds.
