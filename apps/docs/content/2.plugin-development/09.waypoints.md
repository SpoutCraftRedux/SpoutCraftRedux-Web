::warning
**Planned.** Waypoints are scheduled for Phase 2 and later, with minimap integrations in Phase 6. The API below is a sketch.
::

```java
player.spoutCraftRedux().waypoints()
    .add("myplugin:spawn", spawnLocation, Component.text("Spawn"));
```

## Where waypoints show

| Client | Display |
|---|---|
| Vanilla | The vanilla **locator bar** |
| SpoutCraft Redux client | Optional world-space beacons |
| With Xaero's or JourneyMap | Waypoints added through those mods' APIs |

A built-in minimap and overview map are planned for a later phase. Until then, and alongside them, waypoints integrate with the minimap mods players already use.
