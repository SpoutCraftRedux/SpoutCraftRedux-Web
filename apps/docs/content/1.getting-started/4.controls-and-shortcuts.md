With the mod installed, **Options › Controls › Key Binds…** opens the SpoutCraft Redux Controls screen instead of Minecraft's key binds list. Options › Controls itself stays as it is, with the mouse settings and toggles.

## The Controls screen

- A search field filters the list as you type.
- Checkboxes pick which bindings to show:
  - **Minecraft Bindings** (yellow): Minecraft's own and other mods' keys
  - **SpoutCraft Redux** (red): the mod's own keys
  - **Custom Bindings** (blue): keys a server declares, once [server keybinds](/plugin-development/keybinds) arrive
  - **Shortcuts** (green): your own shortcuts
- Below the list are **Add Shortcut**, **Edit** and **Delete**, and **Done** closes the screen.

### Rebinding

Double-click a row, then press the key or mouse button you want. The row shows `> <` while it waits. Press Esc to unbind it.

Two bindings on the same key show in red. The F3 combinations and the spectator hotbar key are never flagged, because they only fire with F3 held or in spectator mode.

### Deleting

**Delete** asks "Really?" first. Click it again within 3 seconds to confirm. On a Minecraft binding it unbinds the key; on a shortcut it removes the shortcut.

## Modifier keys

Any binding can need Ctrl, Shift, Alt or a mix of them, including Minecraft's own and other mods' bindings. Hold the modifiers while you press the key. A binding with modifiers only fires while exactly those modifiers are held.

On macOS, Cmd counts as Ctrl, as in Minecraft's own shortcuts, and shows as `Cmd+`.

### F3 combinations

The debug combinations show as `F3+key`, for example `F3+C`, using whatever the debug key is bound to. When you rebind one:

- hold F3 while pressing the new key to keep it a combination
- press the key alone to make it a standalone key that works without F3

## Shortcuts

A shortcut is a key you make that sends one or more chat messages or `/commands`. Click **Add Shortcut** (or select one and click **Edit**) to open the editor:

- **Name**: shown in the Controls list
- **Key**: click the key button, then press the key, with any modifiers
- **Command**: type a chat message or `/command` and click **Add Command**. To change one, select it, click **Edit Command**, change it and click **Finish Editing**. **Remove Command** deletes the selected one.
- **Delay (ms)**: how long to wait between commands

A shortcut fires when you release its key while no screen is open.

## Where it's saved

| File | Contents |
|---|---|
| `config/spoutcraftredux/bindings.json` | The modifier keys each binding needs, and which F3 keys work without F3 |
| `config/spoutcraftredux/shortcuts.json` | Your shortcuts |

Minecraft's own key choices stay in `options.txt` as usual.
