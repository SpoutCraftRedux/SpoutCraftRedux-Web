The SpoutCraft Redux source lives on [GitHub](https://github.com/SpoutCraftRedux). The main repository holds three separate Gradle builds, each with its own wrapper.

| Folder | What it builds | Command |
|---|---|---|
| `protocol/` | The shared wire format and its tests | `./gradlew test` |
| `client/` | The Fabric client mod | `./gradlew build`, output in `build/libs/` |
| `server/` | The Purpur fork (paperweight-patcher) | `./gradlew applyAllPatches`, then `./gradlew createMojmapPaperclipJar` |

## Requirements

- **Java 25**
- **Git.** The server build has two extra rules:
  - It must run inside a Git clone, because paperweight uses Git to apply patches.
  - The jar tasks need at least one commit, because they stamp the commit hash into the jar.

## Try it locally

::steps{level="3"}

### Start the server

```bash [Terminal]
cd server
./gradlew applyAllPatches
./gradlew runDevServer
```

The dev server runs from `server/run/`.

### Allow offline accounts

Dev clients use offline accounts. In `server/run/server.properties`, set:

```properties [server.properties]
online-mode=false
white-list=false
```

### Start the client

```bash [Terminal]
cd client
./gradlew runJoinLocal
```

This launches the game with the mod and joins `localhost:25565`.

### Check the handshake

Run `/spoutcraftredux list` on the server. Each player shows as SpoutCraft Redux or vanilla.

::

### Test plugin

The server build includes an optional test plugin that logs the SpoutCraft Redux join events. To enable it, create `server/test-plugin.settings.gradle.kts`:

```kotlin [test-plugin.settings.gradle.kts]
include(":test-plugin")
```

## Repository layout

```text
SpoutCraftRedux/
├─ protocol/                 # message records and codecs, no Minecraft dependency
├─ server/                   # paperweight-patcher build
│  ├─ spoutcraftredux-api/     # public plugin API
│  ├─ spoutcraftredux-server/  # server implementation and patches
│  └─ test-plugin/
└─ client/                   # Fabric mod (Loom)
```

The `protocol` module is plain Java 25 and is included by both the client and server builds, so the wire format is defined once.
