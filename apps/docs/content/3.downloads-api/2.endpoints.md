All examples use the `spoutcraftredux-server` project. The client project, `spoutcraftredux-fabric`, works the same way. Values shown are examples.

## List projects

```http
GET /v2
```

```json
{
  "projects": ["spoutcraftredux-server", "spoutcraftredux-fabric"]
}
```

## Get a project

```http
GET /v2/{project}
```

Returns the versions that have builds, oldest first. `metadata.current` is the newest version.

```json
{
  "project": "spoutcraftredux-server",
  "metadata": {
    "current": "26.3"
  },
  "versions": ["26.3"]
}
```

## Get a version

```http
GET /v2/{project}/{version}
```

Returns every build number for the version, oldest first, and the latest successful build. `latest` is `null` when no build has succeeded yet.

```json
{
  "project": "spoutcraftredux-server",
  "version": "26.3",
  "builds": {
    "latest": "42",
    "all": ["40", "41", "42"]
  }
}
```

## Get a build

```http
GET /v2/{project}/{version}/{build}
GET /v2/{project}/{version}/latest
```

```json
{
  "project": "spoutcraftredux-server",
  "version": "26.3",
  "build": "42",
  "result": "SUCCESS",
  "timestamp": 1794830400000,
  "duration": 184000,
  "commits": [
    {
      "author": "Jane Doe",
      "email": "jane@example.com",
      "description": "Add handshake timeout setting",
      "hash": "3f2a9c1e8b7d6a5f4e3d2c1b0a9f8e7d6c5b4a39",
      "timestamp": 1794829800000
    }
  ],
  "md5": "9e107d9d372bb6826bd81d3542a419d6",
  "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "file_name": "spoutcraftredux-paperclip-26.3.build.42-stable.jar",
  "size": 52428800
}
```

### Build fields

::field-group
  :::field{name="project" type="string"}
  The project ID.
  :::

  :::field{name="version" type="string"}
  The Minecraft version.
  :::

  :::field{name="build" type="string"}
  The build number, as a string.
  :::

  :::field{name="result" type="string"}
  `SUCCESS` or `FAILURE`. Failed builds cannot be downloaded.
  :::

  :::field{name="timestamp" type="number"}
  When the build finished, in milliseconds since the Unix epoch.
  :::

  :::field{name="duration" type="number"}
  How long the build took, in milliseconds.
  :::

  :::field{name="commits" type="object[]"}
  The commits included since the previous build. Each has `author`, `email`, `description`, `hash` and `timestamp` (milliseconds since the epoch).
  :::

  :::field{name="md5" type="string"}
  Hex MD5 of the jar.
  :::

  :::field{name="sha256" type="string"}
  Hex SHA-256 of the jar. Prefer this for verification.
  :::

  :::field{name="file_name" type="string"}
  The jar's file name.
  :::

  :::field{name="size" type="number"}
  The jar's size in bytes.
  :::
::

## Download a build

```http
GET /v2/{project}/{version}/{build}/download
GET /v2/{project}/{version}/latest/download
```

Returns the jar as `application/java-archive`, with these headers:

| Header | Value |
|---|---|
| `Content-Disposition` | `attachment; filename="<file_name>"` |
| `Content-Length` | The size in bytes |
| `X-Checksum-SHA256` | The jar's SHA-256 |

## Errors

Errors use standard HTTP status codes with a JSON body:

```json
{
  "statusCode": 404,
  "statusMessage": "Build not found"
}
```

| Status | Meaning |
|---|---|
| `400` | A version or build value contains invalid characters |
| `404` | Unknown project, version or build; no successful build for `latest`; or the build failed (on `download`) |
