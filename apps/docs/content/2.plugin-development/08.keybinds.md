A plugin declares named keybinds with a default key. Modded players see them under **Custom Bindings** in the Controls screen and can rebind them, with modifier keys, like any other binding.

```java
var scr = player.spoutCraftRedux();
scr.keybinds().declare("myplugin:menu", Key.M, "Open menu",
    ctx -> scr.open(menu));
```

Presses also fire `SpoutCraftReduxKeybindEvent`.

## How it works

- The server sends its keybind declarations during login, so they are ready before the player enters the world.
- Use your plugin's namespace in the ID, such as `myplugin:menu`.
- The client only reports presses of keybinds the server declared. It never forwards raw keyboard input.
- Server keybinds are removed when the player disconnects.

## Vanilla fallback

None. Vanilla Minecraft has no server-defined keybinds. Offer a command or an item as an alternative for vanilla players.
