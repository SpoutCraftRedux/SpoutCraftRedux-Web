Sky settings are per player and apply on top of the current dimension.

```java
player.spoutCraftRedux().sky()
    .skyColor(0x330044)
    .fogColor(0x220033)
    .cloudHeight(200)
    .moonScale(2.0);
```

## Settings

| Setting | Effect |
|---|---|
| Sky, fog and cloud colour | Override the vanilla colours |
| Cloud height | Move the cloud layer up or down |
| Stars | Change how many stars show |
| Sun and moon | Scale, visibility, and a custom texture (sent as a hash-checked asset) |

Settings reset when the player changes world or disconnects. The server sends the spawn world's sky during login, so a player never sees a flash of the vanilla sky first.

Per-player weather overrides are also planned, later.

## Players without the client

They keep the normal sky. Per-player sky changes need the client mod.
