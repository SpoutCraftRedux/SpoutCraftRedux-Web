## Built-in sounds

Built-in sounds work through the normal Paper API today and need no client mod:

```java
player.playSound(location, Sound.ENTITY_EXPERIENCE_ORB_PICKUP, 1.0f, 1.0f);
```

## Custom sounds

Put your sound files and `sounds.json` in a resource pack folder in your plugin, and add it with `SpoutCraftRedux.assets().addResourcePack(this, "resourcepack")`. The server merges every plugin's pack, hosts it and sends it to every player on join, so custom sounds play for vanilla players too. See [Images and resource packs](/plugin-development/images-and-resource-packs).

```java
player.playSound(location, "myplugin:shop.open", 1.0f, 1.0f);
```

## Streaming from a URL

The original Spoutcraft could play music from a URL. SpoutCraft Redux plans this as an optional feature: HTTPS only, and only if the player allows it for that server.

## Music control

With the client mod, plugins will be able to stop music with a fade-out and listen for background music changes.
