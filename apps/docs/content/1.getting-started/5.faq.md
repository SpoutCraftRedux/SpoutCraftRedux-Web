:::accordion-item{label="Do players need the client mod to join?" icon="i-lucide-users"}
No. Vanilla clients join normally. The server waits up to `handshake.timeout-ticks` (2 seconds by default) for the mod to answer, then treats the player as vanilla and sends them a chat message with a link to download the client. Client features such as popups and the HUD do nothing for them, while movement and the server resource pack still work. See [players without the client](/plugin-development/players-without-the-client).
:::

:::accordion-item{label="Will my Paper and Purpur plugins still work?" icon="i-lucide-puzzle"}
Yes. The SpoutCraft Redux server is a Purpur fork that adds new code in its own package and keeps patches to Paper and Purpur small. Plugins written for Paper or Purpur 26.3 run unchanged.
:::

:::accordion-item{label="Is this the original Spoutcraft?" icon="i-lucide-history"}
No. It is a new implementation inspired by the original. The original patched `minecraft.jar` directly and targeted Minecraft 1.6.4. SpoutCraft Redux is a regular Fabric mod and a Purpur fork, and its API uses modern names rather than the old `SpoutPlayer` and `GenericButton` classes.
:::

:::accordion-item{label="Which Minecraft versions are supported?" icon="i-lucide-tag"}
Minecraft 26.3 on Java 25. The project plans to move to 26.4 once Paper and Purpur support it.
:::

:::accordion-item{label="Is there a NeoForge version?" icon="i-lucide-box"}
Not yet. The client is Fabric first. A NeoForge adapter, built from a shared common module, is planned.
:::

:::accordion-item{label="Does it run on Folia?" icon="i-lucide-cpu"}
No. SpoutCraft Redux is a Purpur fork, and Purpur does not use Folia's regionized threading.
:::

:::accordion-item{label="Can a server use the mod to spy on me?" icon="i-lucide-shield"}
The mod is designed against that. It never runs code from the server, only reads the clipboard or takes a screenshot after asking you, only downloads hash-checked assets listed by the server, and only reports presses of keybinds the server declared. Usage stats are opt-in, off by default and anonymous.
:::

:::accordion-item{label="Is there a minimap?" icon="i-lucide-map"}
Not yet. A minimap and an overview map are planned. Waypoints will also integrate with existing minimap mods such as Xaero's and JourneyMap.
:::

:::accordion-item{label="Are custom blocks coming back?" icon="i-lucide-blocks"}
Eventually. Custom blocks are the hardest feature and are scheduled last, after a design decision between mapping to spare vanilla block states, entity-backed blocks, and client registry injection.
:::

:::accordion-item{label="What license is SpoutCraft Redux under?" icon="i-lucide-scale"}
The project's own code is LGPL-3.0. Because the server fork contains Paper and Purpur code, the server as a whole is distributed under the GPL-3.0. See [license](/contributing/license).
:::
