SpoutCraft Redux servers accept vanilla clients. Instead of making every plugin check `isModded()`, each API call has a defined behaviour for vanilla players: a vanilla equivalent where one exists, a best-effort approximation, or nothing.

## Feature table

| Feature | With the client mod | Vanilla client | Status |
|---|---|---|---|
| Handshake and join events | `SpoutCraftReduxClientReadyEvent` | `SpoutCraftReduxClientMissingEvent` | Available |
| [Popup GUIs](/plugin-development/guis) | Native widget screens | Converted to a dialog | Planned |
| [HUD widgets](/plugin-development/hud) | Free-form overlay | Action bar, boss bar or title | Planned |
| Hide or move vanilla HUD | Supported | Nothing | Planned |
| [Sky and fog](/plugin-development/sky) | Per-player sky | Nothing | Planned |
| [Custom sounds](/plugin-development/sounds) | From the resource pack | From the resource pack | Planned |
| Music fade-out | Fades | Stops immediately | Planned |
| [Keybinds](/plugin-development/keybinds) | Server controls category | Nothing | Planned |
| [Waypoints](/plugin-development/waypoints) | Beacons, minimap mods | Locator bar | Planned |
| [Capes](/plugin-development/capes) | Server cape | Nothing | Planned |
| Nameplates | Native override | Text display or team prefix | Planned |
| [Notifications](/plugin-development/notifications) | Popup with an item icon | Action bar | Available |
| [Movement](/plugin-development/movement) | Vanilla attributes | Vanilla attributes | Available |
| Floating text, particles, open URL, sign editor | Vanilla | Vanilla | Planned wrappers |
| Custom items | Data components and resource pack | Same | Planned |

## Detecting the client

When a plugin does need to branch, use the player view:

```java
if (player.spoutCraftRedux().isModded()) {
    // richer path
}
```

Or listen for the handshake events described in the [Player API](/plugin-development/player-api#handshake-events).

::tip
Treat the client mod as an enhancement. Design the vanilla path first, then add what the mod makes possible.
::
