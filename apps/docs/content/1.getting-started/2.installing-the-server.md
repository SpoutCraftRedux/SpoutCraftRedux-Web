The SpoutCraft Redux server is a fork of Purpur for Minecraft 26.3. It ships as a single paperclip jar and replaces the Purpur (or Paper) jar you already use.

## Requirements

- **Java 25** or newer.
- A Minecraft **26.3** world, or an empty folder for a new server.

## Download

Get the latest build from [spoutcraftredux.org/downloads](https://spoutcraftredux.org/downloads), or fetch it from the [downloads API](/downloads-api):

```bash [Terminal]
curl -fL -o spoutcraftredux.jar \
  https://api.spoutcraftredux.org/v2/spoutcraftredux-server/26.3/latest/download
```

Each build lists its SHA-256 checksum. See [verifying a download](/downloads-api/examples#verify-a-download) to check it.

## Run it

::steps{level="3"}

### Start the server once

Run the jar from the server folder. On the first start, paperclip patches the vanilla server and writes the default config files.

```bash [Terminal]
java -Xms2G -Xmx2G -jar spoutcraftredux.jar --nogui
```

### Accept the EULA

Set `eula=true` in `eula.txt`, then start the server again.

### Add your plugins

Drop Paper and Purpur plugins into `plugins/` as usual. Plugins built for SpoutCraft Redux go there too.

::

::tip
Moving from Purpur or Paper? Stop the server, replace the jar, and start it again. Worlds, plugins, `paper-global.yml` and `purpur.yml` stay as they are.
::

## Configuration

SpoutCraft Redux reads its own settings from `spoutcraftredux.yml` in the server folder, next to `purpur.yml`. The file is created with defaults on first start.

```yaml [spoutcraftredux.yml]
handshake:
  # How long to wait for the SpoutCraft Redux client to answer while a player connects. 20 ticks = 1 second.
  timeout-ticks: 40
  # Skip the wait for clients that report the "vanilla" brand.
  skip-for-vanilla-brand: true
missing-client:
  # Chat message for players who join without the SpoutCraft Redux client, in MiniMessage format. Empty sends nothing.
  message: "<gold>This server uses <yellow>SpoutCraft Redux</yellow>. Get the client at <click:open_url:'https://spoutcraftredux.org/downloads'><aqua><underlined>spoutcraftredux.org</underlined></aqua></click> for the full experience."
  # Disconnect message for players without the client when a plugin adds custom items or blocks, which they can't play without. MiniMessage format.
  kick-message: "<gold>This server needs <yellow>SpoutCraft Redux</yellow>.</gold><newline><gray>Get the client at <aqua>spoutcraftredux.org/downloads</aqua>"
resource-pack:
  # Port of the built-in web server that hands out the merged plugin resource pack.
  port: 25580
  # Set this if players reach the pack through a proxy or another host, like https://pack.example.com. Empty uses the address players joined with.
  public-url: ''
  # Kick players who decline the pack.
  required: false
  # Message shown when asking players to accept the pack. Empty uses Minecraft's default.
  prompt: ''
```

::field-group
  :::field{name="handshake.timeout-ticks" type="int"}
  How long the server waits for the client mod to answer during login. Players without the mod see this as a short extra delay before joining. Default `40` (2 seconds); minimum `1`.
  :::

  :::field{name="handshake.skip-for-vanilla-brand" type="boolean"}
  When `true`, clients that report the `vanilla` brand skip the wait entirely. Default `true`.
  :::

  :::field{name="missing-client.message" type="string"}
  Chat message for players who join without the client, in [MiniMessage](https://docs.advntr.dev/minimessage/format.html) format. The default links to the downloads page. Empty sends nothing. Plugins can change it per player; see [players without the client](/plugin-development/players-without-the-client#the-download-message).
  :::

  :::field{name="missing-client.kick-message" type="string"}
  Disconnect message for players without the client on a server with [custom items](/plugin-development/custom-items), in MiniMessage format.
  :::

  :::field{name="resource-pack.port" type="int"}
  Port of the built-in web server that serves the merged [plugin resource pack](/plugin-development/images-and-resource-packs). Open it in your firewall. Default `25580`.
  :::

  :::field{name="resource-pack.public-url" type="string"}
  For servers behind a proxy or CDN, such as `https://pack.example.com`. The pack URL becomes `<public-url>/pack/<sha1>.zip`. Empty uses the address the player joined with and `resource-pack.port`.
  :::

  :::field{name="resource-pack.required" type="boolean"}
  Kick players who decline the pack. Default `false`.
  :::

  :::field{name="resource-pack.prompt" type="string"}
  The message on the accept screen. Empty uses Minecraft's default.
  :::
::

## Check who is modded

The `/spoutcraftredux list` command prints the protocol version and every online player's status:

```text
SpoutCraft Redux, protocol 1
 Alex: SpoutCraft Redux 0.1.0 (protocol 1)
 Steve: vanilla
```

The command needs the `spoutcraftredux.command.spoutcraftredux` permission, which operators have by default.

## Testing with offline accounts

Development builds of the client usually run with offline accounts. To test them against a local server, set these in `server.properties`:

```properties [server.properties]
online-mode=false
white-list=false
```

::caution
Never run a public server with `online-mode=false`.
::
