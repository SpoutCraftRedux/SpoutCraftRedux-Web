HUD widgets are drawn over the game while the player plays, without taking input. They use the same widgets as [GUIs](/plugin-development/guis).

## Attaching widgets

```java
var hud = player.spoutCraftRedux().hud();

Label mana = Label.text(Component.text("Mana: 80/100"))
    .at(Anchor.TOP_LEFT, 4, 4);
hud.attach(mana);
```

Changes to an attached widget are sent as small diffs, so updating a counter every tick stays cheap.

## Vanilla HUD elements

With the client mod, plugins can also hide or move the vanilla HUD bars, such as health, armor, hunger, experience and air.

```java
hud.hide(HudElement.HUNGER);
hud.move(HudElement.HEALTH, Anchor.BOTTOM_LEFT, 8, -8);
```

## Planned extras

- Anchors that stay correct at every GUI scale

## Vanilla fallback

Vanilla clients have no free-form HUD. The server makes a best effort with the action bar, the boss bar or titles, depending on the widget. Hiding or moving vanilla HUD elements does nothing on vanilla clients.
