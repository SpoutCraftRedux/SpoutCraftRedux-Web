## Capes

A server can set a cape texture on any player. The texture is sent as a runtime asset: content-addressed by SHA-256, PNG only, and size-limited. Players with the client mod see the cape on that player.

```java
player.spoutCraftRedux().appearance()
    .cape(CapeTexture.fromPlugin(this, "capes/founder.png"));
```

Vanilla clients cannot show server capes, so they see the player's normal cape or none.

## Nameplates

Multi-line, coloured name titles are planned too. With the client mod they replace the native nameplate; vanilla clients get a text display riding above the player, or scoreboard team prefixes.
